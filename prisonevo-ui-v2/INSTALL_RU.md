# Установка и проверка

Комплект предназначен для **Paper 1.21.8 / Java 21 / клиента Minecraft Java 1.21.8**.

## 1. Сначала подключить графику на своём клиенте

1. Скачай `PrisonEvo-UI-resourcepack-1.21.8.zip` через кнопку **Download raw file** на GitHub.
2. В игре: **Настройки → Наборы ресурсов → Открыть папку**.
3. Положи туда ZIP **целиком**, не распаковывая, и включи его. Это дополнительный пак со своим namespace; существующий пак сервера сохраняется.
4. При необходимости обнови ресурсы сочетанием `F3+T`.
5. С правами оператора можно проверить отдельную модель командой Minecraft 1.21.8:

```mcfunction
/give @s minecraft:paper[minecraft:item_model="prisonevo:storage"]
```

Должна появиться бочка с ресурсами, а не бумага или чёрно-розовый квадрат.

## 2. Подключить меню на тестовой копии сервера

JAR основан именно на `prisonevo/PrisonEvo-test-0.1.0.zip` из этого репозитория. Если разработчик уже изменил твою рабочую версию, этот тестовый JAR не следует ставить поверх неё: нужно перенести изменения из `ModernMenu.java`, `UiLayout.java` и вызовы из `PrisonEvo.java` в актуальные исходники.

1. Останови тестовый сервер. Сохрани копии прежнего JAR PrisonEvo, папки `plugins/PrisonEvo/` и связанного мира. Существующий ресурс-пак также сохраняется перед объединением.
2. Убери старый JAR PrisonEvo из `plugins/` и положи `plugin/prisonevo-0.1.1-ui.jar`. В папке не должно оставаться двух JAR этого плагина. Старый файл держи в резервной копии вне `plugins/`.
3. **Не заменяй** `islands.yml`, мир и существующие настройки. Добавь только этот раздел в `plugins/PrisonEvo/config.yml`:

```yaml
ui:
  enabled: true
```

Если раздел `ui` уже есть, измени значение в нём, не создавая второй одноимённый ключ.

4. Запусти сервер. Открой `/pe` или `/prisonevo menu`.

По умолчанию `ui.enabled` выключен: без этой настройки остаётся прежнее предметное меню. Новое меню не проверяет наличие локального пака автоматически; сначала подключи пак из шага 1.

## 3. Что проверить в игре

- Главное меню: три верхние карточки «Остров», «Бур», «Склад»; нижние «Шахта», «Развитие», «Помощь».
- Без острова карточка острова должна предлагать его создание в подсказке. Остальные хозяйственные разделы просят сначала создать остров.
- На складе число совпадает с подсказкой; продажа обнуляет склад и увеличивает внутренний баланс один раз.
- Улучшения показывают реальные цену и уровень; покупка сохраняет их в существующих данных.
- «Назад», крестик и «На сервер» работают. Последняя кнопка возвращает в сохранённую точку входа из исходного плагина, а не обязательно на фиксированный спавн.
- ЛКМ, Shift-клик, цифровые клавиши, двойной клик, Q и перетаскивание не должны позволять забирать кнопки или переносить предметы в меню.
- Рамки совпадают с инвентарём при разных настройках масштаба интерфейса. При наведении видна обычная подсветка одного слота Minecraft — это ожидаемо.

Если видны бумажки или неизвестные символы, нужный ресурс-пак не загрузился: верни `ui.enabled: false` и перезапусти сервер до устранения причины. Для отката самого плагина используй сохранённый старый JAR; структуры мира и данных в этой UI-сборке не менялись.

## 4. Выдать оформление всем через Nexo

Локальная установка проверяет графику у тебя. Для остальных игроков namespace `assets/prisonevo` должен попасть в ресурс-пак, который выдаёт Nexo.

В комплекте уже есть готовое содержимое `resourcepack/assets/prisonevo/`. Его нужно **добавить** в исходную структуру твоего Nexo-пака, сохранив эти относительные пути, и пересобрать пак штатным для твоей версии Nexo способом. Чужой `pack.mcmeta` из тестового ZIP в Nexo не копировать; файлы существующего `assets/minecraft` не заменять. Не меняй адрес выдаваемого ресурс-пака на тестовый ZIP: в нём нет остальных ресурсов сервера.

Точная папка импорта и команда пересборки здесь намеренно не указаны: версия Nexo, его конфигурация и текущий пак не предоставлены. Для окончательного объединения нужны архив исходной папки ресурс-пака Nexo, его настройки сборки и актуальный JAR/исходники PrisonEvo. DeluxeMenus и FancyNpcs для этого меню менять не требуется: обработчики находятся в самом плагине, команды входа сохранены.

## Сборка исходников

Полный JDK 21 и Maven:

```bash
cd plugin-source
mvn test package
```

Перерисовка графики с официальным клиентским JAR 1.21.8:

```bash
python -m pip install Pillow
python source/build_art.py /path/to/1.21.8.jar
```

`build_art.py` пересоздаёт `png/`, `previews/`, `resourcepack/` и ZIP ресурс-пака. Текстуры не сглаживаются.
