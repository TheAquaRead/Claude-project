# HYLOR — Prison Evo | локальная демоверсия 0.3

Пять шахт, 25 рангов, улучшения добычи, контракты трёх типов, автошахта, эволюция и пять NPC на отдельной карте. Добыча начисляет монеты сразу; у каждого блока есть шанс 5% на тройную награду. Розовый прогресс-бар показывает баланс, ранг и состояние контракта. Авторский ресурс-пак меняет иконки предметов на пиксельные в цветах HYLOR.

## Как проверить

1. Распакуйте архив в пустую папку. На Windows дважды нажмите `start.bat`. Для Linux x86-64 запустите `sh start.sh`.
2. Ознакомьтесь с https://aka.ms/MinecraftEULA. Если принимаете соглашение, введите Y. При первом старте скрипт скачает Java 25, а Paper скачает необходимые файлы Minecraft; нужен интернет. Следующие запуски используют локальные файлы.
3. Дождитесь сообщения `Done` и запустите Minecraft Java Edition **26.3**. Подключитесь к `localhost`. Сервер использует проверку учётной записи Minecraft.
4. При входе согласитесь на ресурс-пак HYLOR. Он раздаётся локально с адреса 127.0.0.1:8765. Если окно не появилось, разрешите серверные ресурсы в настройках сервера в Minecraft и перезайдите. При занятом порте 8765 пак не загрузится; проверьте журнал сервера.
5. Для корректного сохранения введите `stop` в окне сервера. Сервер настроен для локальной проверки на этом компьютере и не открыт для других устройств.

На macOS и других архитектурах установите Java 25 самостоятельно и запустите `java -Xms1G -Xmx2G -jar paper.jar --nogui` после принятия EULA. Если Linux-файл не запускается двойным нажатием, используйте команду выше через терминал. Запуск на Windows не проверен в Linux-окружении разработчика.

## Игровые команды

- `/spawn` — вернуться в центр.
- `/mines` — выбрать доступную шахту. Следующие открываются с 6, 11, 16 и 21 ранга.
- `/shop` — повысить ранг и доход от добычи; улучшение постепенно ускоряет стартовую кирку.
- `/kit` — бесплатно получить стартовую кирку.
- `/quests` — контракты на добычу блоков, руды и редкой руды.
- `/auto` — автошахта с 5 ранга: улучшайте её и забирайте прибыль. Она работает, только пока игрок в сети; объём хранилища ограничен.
- `/evo` — эволюция за 25 000 монет на 25 ранге. Ранг сбрасывается, улучшения сохраняются, доход растёт.
- `/balance` — текущий баланс и прогресс.

Прогресс записывается в `plugins/HylorPrisonEvo/players.yml` раз в минуту, при выходе игрока и при остановке сервера. Резервируйте каталог плагина и мир `hylor_prison`. Обновление со старого прототипа: используйте новую папку, поскольку старый формат баланса автоматически не переносится.

Демо рассчитано на локальный просмотр, а не на открытый сервер. Карта создаётся блоками автоматически; донатные привилегии и внешняя система оплаты не подключены. Полноценное тестирование с игроками и финальная балансировка остаются необходимыми перед публичным запуском.
