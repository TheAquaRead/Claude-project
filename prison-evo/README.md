# HYLOR Prison Evo — версия 0.2

Ранняя игровая версия для Paper 26.3 и Minecraft Java 26.3. Создаёт отдельный мир hylor_prison с розово-чёрным спавном, пятью шахтами и NPC. Это ещё не законченная публичная сборка: нужна проверка игрового баланса и совместной игры, доработка карты, цепочек квестов, донатных привилегий и фирменного ресурс-пака.

## Запуск

1. Распакуйте архив. Требуется Java 25 и доступ к интернету для первого запуска Paper.
2. Прочитайте https://aka.ms/MinecraftEULA; если принимаете соглашение, откройте eula.txt и замените `eula=false` на `eula=true`.
3. В Windows запустите start.bat. В Linux выполните `sh start.sh`.
4. Подключитесь клиентом Minecraft Java 26.3. При первом старте карта будет создаваться автоматически.

Если переходите с прототипа 0.1, сделайте резервную копию всей папки сервера: версия 0.2 использует другую структуру баланса и не переносит старые монеты автоматически. Начните с чистой папки для честного тестирования.

## Игра

Добывайте блоки киркой — монеты начисляются сразу. `/mines` открывает выбор шахт; новые шахты доступны с 6, 11, 16 и 21 ранга. В `/shop` повышайте ранг и доход от добычи. `/kit` выдаёт бесплатную стартовую кирку. `/quests` показывает повторяемый контракт. В `/auto` открывайте и улучшайте автошахту начиная с 5 ранга; её монеты копятся только во время пребывания игрока на сервере и ограничены размером хранилища. `/evo` открывает эволюцию на 25 ранге за 25 000 монет: ранг сбрасывается, а улучшения сохраняются. `/balance` показывает прогресс, `/spawn` возвращает на спавн.

Прогресс сохраняется в plugins/HylorPrisonEvo/players.yml при выходе игрока, раз в минуту и при выключении сервера. Останавливайте сервер командой stop и сохраняйте резервные копии папок мира и плагина.
