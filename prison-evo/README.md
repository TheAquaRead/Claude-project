# HYLOR Prison Evo — прототип

Тестовая версия для Minecraft Java 26.3 / Paper 26.3. Содержит пять автоматически создаваемых шахт, 25 рангов, магазин, продажу ресурсов, одно повторяемое задание, NPC и автошахту, которая начисляет монеты только когда игрок в сети. Прогресс хранится в plugins/HylorPrisonEvo/players.yml. Карта создаётся в основном мире около координат 0, 100, 0 при первом запуске; используйте новый мир.

Установите Java 25, распакуйте архив, прочитайте https://aka.ms/MinecraftEULA и при согласии измените eula=false на eula=true в eula.txt. Запустите start.bat или start.sh. При первом запуске Paper скачает необходимые файлы. Команды: /spawn, /mines, /shop, /auto, /quest, /sell, /balance. Автошахта открывается с 5 ранга.

Это ранний прототип: пока отсутствуют эволюции, донатные привилегии, ресурс-пак и законченная авторская карта. Игровой баланс, защита и совместная игра требуют проверки перед публичным запуском.
